# 鬼月三十夜：試玩版

這個儲存庫只放打包好的遊戲，給 GitHub Pages 用；原始碼不在這裡。

- 試玩：https://realkazuya.github.io/ghostshift-play/
- 需要電腦：鍵盤滑鼠（WASD 移動、滑鼠瞄準、左鍵施法）或手把。建議用 Chrome 或 Edge。
- 進度存在你自己的瀏覽器裡（清完一波自動存檔）。
- 回饋：遊戲中按 F8，寫下筆記後會下載一個回饋檔（截圖、最近兩段重播、筆記），把檔案交給開發者。
- 音效與配樂試聽：https://realkazuya.github.io/ghostshift-play/audio.html
- 第三方授權：`licenses/`
